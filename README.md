# nf-coding-challenges

Challenges and side projects from the neuefische bootcamps, one folder per course.

## Web Development (`wd-challenges`)

- [`html`](wd-challenges/html): HTML basics (div salad, find the errors, format salad)
- [`html-forms`](wd-challenges/html-forms): forms, validation and accessibility errors
- [`css-basics`](wd-challenges/css-basics): selectors and pseudo-classes (button styles, Pokémon page, pseudo park)
- [`css-structure`](wd-challenges/css-structure): BEM, custom properties and a taco truck page
- [`css-positioning`](wd-challenges/css-positioning): absolute positioning and layouts with `position`
- [`css-flexbox`](wd-challenges/css-flexbox): flexbox navigation, profile, component and layout
- [`css-grid`](wd-challenges/css-grid): grid galleries, cards and placing elements
- [`css-responsive`](wd-challenges/css-responsive): media queries and a responsive website
- [`css-animation`](wd-challenges/css-animation): CSS and JavaScript-driven animations
- [`shell-basics_treasure-hunt`](wd-challenges/shell-basics_treasure-hunt): navigating the shell on a treasure hunt
- [`js-structure`](wd-challenges/js-structure): JavaScript modules with `import`/`export` (quiz app, shapes, space rocket)
- [`js-basics-and-variables`](wd-challenges/js-basics-and-variables): variables and calculations (tip, savings, lifetime calculators)
- [`js-dom-and-events`](wd-challenges/js-dom-and-events): DOM events (dark mode, calculator, survey fixes)
- [`js-conditions-and-booleans`](wd-challenges/js-conditions-and-booleans): conditions, truthy/falsy and type checks
- [`js-inputs-and-strings`](wd-challenges/js-inputs-and-strings): input handling and string methods
- [`js-functions`](wd-challenges/js-functions): functions, parameters, arrow functions and DOM manipulation
- [`js-forms`](wd-challenges/js-forms): form submit, checkboxes and a form calculator
- [`js-objects-and-arrays`](wd-challenges/js-objects-and-arrays): objects and arrays
- [`js-createelement`](wd-challenges/js-createelement): building DOM elements (product teaser, toasts, social post)
- [`js-loops`](wd-challenges/js-loops): `for`, `for…of`, `for…in` and `while` loops
- [`js-array-methods`](wd-challenges/js-array-methods): `map`, `filter`, `forEach` and friends, plus small SPAs
- [`js-modern-syntax`](wd-challenges/js-modern-syntax): destructuring, rest and spread
- [`js-fetch`](wd-challenges/js-fetch): fetching APIs (Star Wars, color clue)
- [`js-error-handling`](wd-challenges/js-error-handling): `try`/`catch` in a calculator and with fetch
- [`testingground`](wd-challenges/testingground): pages for trying things out
